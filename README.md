# VEROXAI UNIVERSE — Phase 1 starter

A React + Vite responsive website foundation with:
- Cinematic dark / hot-neon-pink homepage
- GSAP hero and orbital animation
- Six world portals and route architecture
- Explore index and searchable starter archive
- Responsive mobile navigation
- Reusable cards, page components and content data

## Run
Install Node.js, then in this folder run:
1. `npm install`
2. `npm run dev`
3. Open the local URL printed by Vite.

## Notes
The portrait images are temporary editorial placeholders and are not verified likenesses of the named people. Replace them with verified, licensed portraits before publication. The individual world pages are structural placeholders for Phase 2.
